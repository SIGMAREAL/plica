META ◆ 海量图片

数百亿张图片，为什么不能直接各存一个文件？

Facebook 早期 Haystack 系统将大量照片合并到对象存储里，减少传统 NFS 大量文件的 inode/目录元数据查询导致的额外 I/O。

02 / THE DESIGN

三个关键机制

01

早期一张图片一个文件的做法使海量 inode 和目录元数据超过缓存能力。

02

Haystack 将图片内容组织为容器化对象，尽量减少单张图片读取的元数据 I/O。

03

结合 HTTP 服务和空间管理，使存储层更贴近按图片 ID 读取的实际访问模式。

03 / THE TRADE-OFF

设计总有代价

这些是 2009 年的历史规模与设计，不应把 Haystack 作为 Meta 当前所有照片存储的唯一实现。
