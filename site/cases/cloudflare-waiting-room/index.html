CLOUDFLARE ◆ 边缘限流

流量突然爆发时，Cloudflare 如何给用户有序排队？

Cloudflare 基于 Workers 和 Durable Objects↗ 搭建 Waiting Room，在靠近用户的边缘节点控制进入源站的请求，并以逻辑隔离的协调对象聚合队列状态。

01 / THE CONTEXT

为什么值得读

它展示了边缘平台怎样在全球分布的低延迟请求与共享资源限制之间取得平衡。

02 / THE DESIGN

三个关键机制

01

Workers 在请求入口判断进入网站或等待室，降低流量洪峰直达源站的风险。

02

Durable Objects↗ 汇总来自多个边缘入口的计数，并围绕等待室做逻辑隔离。

03

将不同客户的资源配额与协调域分开，缩小单一热点请求对其他队列的影响。

03 / THE TRADE-OFF

设计总有代价

边缘排队可以削峰，但请求分布、计数的新鲜度和全局公平性仍需专门处理。
