02 / THE DESIGN

三个关键机制

01

Agent 循环会频繁创建提交，而 Push 延迟和热门分支写入可能成为新的系统吞吐上限。

02

读扩展可以借缓存与副本改善，但写入持久化和全局可见性的协调更难线性扩展。

03

GitHub 计划减少不必要的同步协调，保留确实用于保障 Git 语义的协调点，同时重新组织数据耐久和扩展能力。
