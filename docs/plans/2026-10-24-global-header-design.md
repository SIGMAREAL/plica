# Plica global header

The previous header flattened a few destinations and promoted either GitHub or a second Explore action. The global navigation now exposes the site's three content groups while the right-hand action consistently leads to the public Agent Skill.

Reference: the current OpenAI Chinese homepage and its expanded Products menu, inspected in a live browser on 2026-10-24. Adopt its compact white header, full-width typographic menu, subdued backdrop and separate right-hand action. Plica's labels and destinations come from its own existing content.

- Six first-level entries: Case Library, Products, Teams, Mechanisms, Knowledge, About Plica.
- Case Library, Products, Teams and Mechanisms are direct links to the existing indexes. These primary browsing dimensions must remain visible in the header.
- Knowledge expands to graph, glossary, research and design comparisons.
- About expands to editorial principles, Skill, sponsorship and GitHub. Appearance is secondary inside this group on desktop.
- Right side: case search and Get Skill. The CTA opens the existing Skill page and download; it does not claim to install a Skill automatically.

Desktop dropdowns support pointer intent, click, arrow-key navigation, Escape with focus return, outside dismissal, focus exit and route changes. The direct entries keep ordinary link behavior and current-page indication. Arrow keys move across all six entries. The sidebar shows the current column's records or the current page's chapter outline; it does not repeat global entry links.

Mobile retains the Skill action in the header. Its full-screen Kumo Dialog exposes the four primary links immediately, followed by the Knowledge and About accordions. It provides focus trapping, scroll locking, Escape/close controls and focus return. Appearance is at the bottom. Reduced-motion preferences disable menu animation.

Scope: the React prototype's shared header and navigation configuration. No backend content, account/authentication behavior, deployment or unrelated page redesign.
