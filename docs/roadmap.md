# Roadmap

Source: [original requirement and implementation records](https://github.com/SIGMAREAL/PEtwinsMacOS/issues/39). Plica's confirmed scope is real software-system meta-architecture, not the retired AI-only Stackworthy concept.

## Implemented in the migrated v1.2 baseline

- Production catalog, original-source links and editorial comparisons.
- Separate Product / Organization / Mechanism indexes and filters, archive search and article details.
- Glossary, reviewed case–term links, knowledge graph with readable mobile lists.
- Separate Research catalog and thematic case associations.
- Static Python generation, validation and relative URLs.
- Public Agent Skill and static read-only indexes.
- Selection-to-question sidebar **preview only**.

Baseline totals: 32 cases, 3 papers, 35 terms, 50 reviewed relations, 130 HTML pages. Implementation is not proof of every source claim; continue editorial verification.

## Migration acceptance

- Recover and hash the actual final Drive archive; keep older deliveries unchanged and record differences.
- Publish complete maintainable source in an independent repository, with CI and actual Pages deployment.
- Verify real HTTP desktop/mobile navigation, root and `/plica/`, search/filter/history, detail/term/graph links, public Skill and generated artifacts.
- Record factual test/deployment results separately from historical release claims.

## Next: maintain and improve

- Source review/corrections workflow, stable IDs, duplicate detection, dates and provenance; link-rot audits.
- Grow product, organization and mechanism coverage without turning research hypotheses into deployment claims.
- Improve glossary/graph accessibility, comparison depth, research metadata and public Skill compatibility.
- Keep static builds reproducible; improve SEO, structured metadata, performance, keyboard/screen-reader coverage and rights review.
- Choose a repository source-code license only after ownership and third-party boundaries are resolved.

## Planned, not implemented

- Authenticated AI reading backend with source-grounded responses, evaluations, rate limits and privacy controls.
- Membership, quotas, subscription/payment processing and server-side usage accounting.
- Real Sponsor and Newsletter services, consent and operational handling.
- Optional editorial tooling, RSS, custom domain and reviewed diagrams as separately scoped work.

These services are outside this migration. Do not present mock controls as live transactions or collect credentials in the public static client.
